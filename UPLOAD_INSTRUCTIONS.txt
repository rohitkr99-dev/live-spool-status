HOW TO APPLY THESE FILES ON GITHUB (WEB BROWSER ONLY)
=======================================================

This zip contains only the NEW and CHANGED files, in the exact same
folder structure as your repo. Unzip it on your computer first -
you'll get one top-level folder called "live-spool-status-changes"
containing everything below.

Because a couple of these are brand-new folders (src/quality/,
data/upload/quality/ already exists), the easiest way to do this
with no git/command line is one folder at a time, using GitHub's
"Add file -> Upload files" button:

1. Go to your repo on github.com, click "Add file" -> "Upload files".
2. On your computer, open the unzipped "live-spool-status-changes"
   folder and drag in the CONTENTS one top-level folder at a time
   (.github, README_DEPARTMENTS.md, config, data, main.py,
   quality_main.py, scripts, src, tests, website) - GitHub preserves
   the folder structure inside whatever you drop in, and will ask
   "replace existing file?" for anything that already exists there
   (say yes to those - config/settings.json, config/column_mapping.json,
   main.py, scripts/sync_drive.py, src/constants.py, src/departments.py,
   src/merge.py, src/pipeline.py, src/reader.py, website/index.html,
   website/quality.html, .github/workflows/drive-sync.yml, and
   data/upload/quality/README.txt are all REPLACING an existing file -
   everything else is brand new).
3. Repeat for each top-level folder until everything from the list
   below has been uploaded.
4. Scroll down and commit directly to main (or open a PR if you
   prefer to review the diff first).
