1. Inputs

Upload a file or paste rows copied from Excel

Pasting: copy the cells in Excel with the heading row. The columns can be in any order, and extra columns are ignored. After you paste, a preview shows how each column was read; if a heading is not recognised, choose the right field in the dropdown above that column. Fields marked * are required. If you both upload and paste, the pasted rows are used.

Cut list columns: Project, Drawing No., Spool No., Item Code, Length, Group, Bevel (optional: Qty).
Available pipes columns: Barcode, Item Code, Length, Control No., Heat No. Length is the current remaining length.
